# Kitchen and menu assets

Created for Foodie on 2026-11-14 using the built-in Imagegen tool. The restaurant covers depict invented businesses and are development seed assets. No third-party restaurant branding or stock photography was used. Logos are original SVG artwork extending the existing Osas monogram approach.

Images are stored as optimised WebP files. Original image generation files remain outside the repository.

Prompt: Use case: photorealistic-natural. Asset type: panoramic 3:1 website restaurant cover photograph. Fictional Nigerian brand: Osas Kitchen. Physical brass signage on the back wall reads exactly 'OSAS KITCHEN'. Keep signage centred in the middle half of the wide frame, readable when cropped to a shallow cover.
